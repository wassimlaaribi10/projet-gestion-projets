# Plateforme Web Collaborative de Gestion de Projets

Application web MERN permettant à des équipes de créer, organiser et suivre leurs projets.

## Stack technique

- **Frontend :** React.js, React Router, Axios
- **Backend :** Node.js, Express.js
- **Base de données :** MongoDB, Mongoose
- **Sécurité :** JWT, bcrypt, Helmet, CORS
- **Tests :** Jest, Supertest
- **DevOps :** Docker, GitHub Actions

## Structure du projet

- `backend/` — API REST
- `frontend/` — Interface utilisateur React
- `docs/` — Documentation, UML, maquettes
